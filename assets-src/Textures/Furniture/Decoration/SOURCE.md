# Abstract wall-art image set (`HOUSE-00982`)

`abstract_13.png` through `abstract_16.png` are bounded 512-pixel derivatives of PuzzleAndy's
**CC0 Abstract Textures** set on OpenGameArt.org. The source page explicitly publishes all sixteen
images under CC0; House Simulator selects only four and records each original URL and SHA-256 in
`assets-src/assets.manifest.json` and `tools/assets/decoration_prepare.py`.

The preparation tool converts the selected JPEGs to deterministic sRGB PNGs. Images 13 and 14 keep
their landscape composition, image 15 receives a centred portrait crop and image 16 a centred
square crop. The corresponding reusable dark, brass and wide-mat frame geometry is generated by
`tools/blender/wall_art_set.py`. This is the plan's one wall-art set and remains below its eight
image ceiling.
